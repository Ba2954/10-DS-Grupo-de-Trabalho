 #  **Oque é Markdown?**
> Markown é uma linguaguem de marcação utilizada para documentos simples, publicada em formato **HTML**. Criada por Aaron Swartz e John Gruber.

 # **Como utilizar Markdown?**
> Markdown é organizado da seguinte forma: Título, Parágrafo, Referência de Bloco, bloco de Código, Lista, Divisor, Link, Imagem, barra e símbolo.
